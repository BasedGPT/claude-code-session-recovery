# Domain Docs

Use this repo's single-context domain documentation when exploring or changing the codebase.

## Before exploring

- Read **`SHARED-LEXICON.md`** at the repo root when it exists. Use its terms for domain concepts in issues, refactor proposals, hypotheses, and test names.
- Read relevant decisions in **`docs/adr/`** when that directory exists. If either source is absent, proceed silently; don't suggest creating it before a real need arises.

## Flag ADR conflicts

If your work would contradict an existing ADR, surface the conflict explicitly rather than silently overriding it.

# v1.0.0

Initial formal release baseline for the Claude Code Desktop session recovery
toolkit.

This release establishes the versioning contract described in
[`docs/release-process.md`](../release-process.md): every future change to the
public repository must advance `VERSION`, pass the release-policy check, and
receive an annotated tag.

Verification for this baseline:

```text
python -m pytest -q tests
python tests/run_fixture_tests.py
```
